Frequently asked

What happens to a file after it's scanned?

The file is uploaded for analysis, processed, and then deleted from our systems. Lasting copies stay with your firm — we don't keep a document library.

Is there a limit on cases or file size?

No case or scan limits on any plan. Very large exhibits may be capped for OCR page count — see the Security & Privacy page for current limits.

Can I try it before switching a whole matter over?

Yes — the 14-day trial covers full functionality. Most firms bring one active matter to the trial to see it against a real filing history.

Do you require a contract?

Per-seat plans are month-to-month at $79/seat. Enterprise plans can be annual if that suits your firm's procurement process.

What about sealed or privileged evidence?

Core forensic checks run inside each analysis job (source PDF deleted immediately). Deeper contextual analysis is opt-in per file — see Security & Privacy before enabling it on restricted material.

Not sure which plan fits your firm?

Tell us how many attorneys will use it and what kind of matters you run — we'll recommend a plan on the call.
