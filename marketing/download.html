Get scanning in three steps

1. Download

Run the Windows installer. Choose an install folder if you prefer.

2. Start trial

Open CaseSifter → Account → Start trial (or Sign in). Scans stay locked until entitlement is active.

3. Add a matter

Create a case, add filings from this PC, and let analysis run two files at a time.

Requirements

  • Windows 10 or 11 (64-bit)
  • Internet access for ephemeral analysis and trial / billing
  • Enough disk for case PDFs (stored only on this machine)
